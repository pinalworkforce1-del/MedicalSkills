# BOOST Healthcare Workplace Skills Challenge — Pilot v1

Sector-specific career-alignment and workplace-learning challenge grounded in Lightcast healthcare skill-demand data.

The pilot includes 8 scenarios, progress and scoring, immediate feedback, skill-level results, pre/post confidence, technical-exposure self-report, reflection, and print/save-as-PDF. Technical exposure is not scored and the challenge is not a hiring or competency assessment.

Add artwork to `assets/images/` and narration to `assets/audio/` using the filenames in `MEDIA_MANIFEST.md`.
